# RGM-LMZ

## Description
Dieses Reifegradmodell hilft Unternehmen, ihren Reifegrad im Bereich digitaler Barrierefreiheit zu messen und durch Handlungsempfehlungen zu verbessern. Dafür stehen den Nutzer\*innen verschiedene Pakete zur Verfügung, die individuell nach Tätigkeit ausgewählt werden können. Die Pakete enthalten Fragen zu bestimmten Tätigkeitsfeldern, bei denen die digitale Barrierefreiheit eine zentrale Rolle spielt. Nach Beantwortung der Fragen, erhält die Nutzer\*in eine Auswertung in Form einer Tabelle und eines Netzdiagramms. Außerdem werden Handlungsempfehlungen gegeben, die bei Berücksichtigung zu einer höheren Stufe führen.
